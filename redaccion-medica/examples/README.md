# Ejemplos por tipo de artículo

**Todos los ejemplos son modelos anotados. No contienen datos de investigación reales.** Las cifras, nombres y referencias están sustituidos por marcadores entre corchetes (`[n]`, `[OR; IC 95 %]`, `[CITA]`). Muestran **estructura, orden y forma de las frases**, no contenido que pueda copiarse. Al usar un ejemplo, cada marcador se llena con el material del usuario o con una fuente verificada; si no hay dato, se queda como `[COMPLETAR]` o `[VERIFICAR]`.

Las extensiones en palabras son orientativas (rango habitual); la revista objetivo manda.

| Tipo de artículo | Guía de reporte | Ejemplo |

| Caso clínico / serie de casos | CARE | `caso-clinico.md` |
| Revisión sistemática y metaanálisis | PRISMA 2020 | `revision-sistematica.md` |
| Revisión narrativa | SANRA (orientativa) | `revision-narrativa.md` |

Cada archivo tiene la misma estructura:
1. Cuándo usarlo y qué pedir al autor.
2. Esqueleto con extensión orientativa.
3. Modelo anotado por sección (frases tipo con marcadores y notas de por qué).
4. Errores típicos que el skill debe evitar.
