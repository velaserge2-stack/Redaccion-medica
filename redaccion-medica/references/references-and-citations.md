# Referencias y búsqueda de evidencia

## Regla central
Una referencia existe y respalda la afirmación solo si se comprobó en la fuente. Si no se pudo, se marca `[VERIFICAR]` o no se incluye. Nunca completar de memoria autores, año, volumen, DOI, PMID ni citas textuales.

## Al reformatear referencias que el usuario ya escribió
Cambiar solo la forma (puntuación, abreviatura de páginas, orden). No agregar, corregir ni "completar" ningún dato desde la memoria: ni título, ni iniciales, ni año, ni volumen, ni páginas, ni DOI, ni la lista de autores. Si algo parece mal, se puede decir que es sospechoso y por qué (p. ej., un año incompatible con el volumen, un prefijo DOI de pruebas), pero el valor correcto lo pone la fuente consultada, no la memoria. En la entrada propuesta, los datos dudosos quedan como `[VERIFICAR]`.

## Búsqueda reproducible
1. Formular la pregunta (PICO si es clínica).
2. Elegir fuentes: PubMed, Europe PMC, Crossref, Cochrane Library, sitios oficiales de guías. Usar las herramientas disponibles en la sesión (búsqueda web, Consensus, etc.).
3. Registrar: fuente, fecha, cadena de búsqueda, filtros, número de resultados. Para revisiones sistemáticas aplicar PRISMA-S.
4. Priorizar la evidencia primaria y las revisiones sistemáticas sobre la opinión editorial; anotar el tipo de cada fuente.
5. Recuperar la fuente original de las afirmaciones importantes, no un resumen de terceros.

## Verificación de cada referencia
| Dato | Cómo | Resultado |
|---|---|---|
| Existencia | DOI resuelve / PMID en PubMed / título en Crossref | Sí / No / No verificable |
| Metadatos | Autores, año, revista, volumen, páginas coinciden | Coincide / Discrepa (anotar) |
| Respaldo | El resumen o texto contiene lo afirmado (cifra, diseño, población) | Respalda / No respalda / Solo resumen leído |
| Vigencia | ¿Retractado, corregido, reemplazado? | Anotar |

Declarar siempre si solo se leyó el resumen. Una cifra citada exige haber visto la cifra en la fuente.

## Citar con precisión
Preferir estudios concretos ("Autor et al., año, diseño, n, resultado principal") a "la literatura sugiere". Pero solo con lo que se verificó; si falta, `[CITA: tema, tipo de estudio esperado]` para que el autor aporte.

## Formato
Aplicar el estilo de la revista (Vancouver/NLM "Citing Medicine", AMA, APA, etc.). Si no se conoce, preguntar o dejar el formato numérico estándar y declararlo. Mantener correspondencia 1:1 entre citas en el texto y lista final; detectar citas huérfanas y entradas no citadas.

## Alertas
- Referencia que no se encuentra en ninguna base: tratarla como posiblemente inexistente y decirlo al usuario.
- Metadatos erróneos (año o autor distinto del real): corregir con la fuente y avisar del cambio.
- Fuente de baja calidad o predatoria: advertir.
